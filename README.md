A 28-second vertical GTA 6 clip cut from Rockstar's official GTA VI Launch Trailer: a police chase, a dirt-bike jump over Vice City, and the make.fun pitch — "Make clips like this with AI and earn money on make.fun". The clip goes up on YouTube as a public Short; places go by its views, and the top 20 share $500.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```

`main.ts` copies `VIDEO.json` (the Short's address) to the output directory, where the house reads it.
